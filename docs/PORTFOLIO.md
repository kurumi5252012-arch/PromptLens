# 作品集介绍与发布素材

## 项目简介

PromptLens 是面向个人开发者的本地提示词对比工具。用户以同一组测试用例运行两版提示词，比较原始回答、可复现规则检查、耗时与 Token 用量，并保存实验快照和导出报告。

## 简历描述

开发 PromptLens 提示词评测工作台，使用 React、TypeScript、Node.js 与 SQLite，实现 A/B 批量评测、受限并发、超时与逐项失败隔离、历史快照和报告导出；以自动化测试覆盖输入校验、替换边界、服务商异常与持久化，并配置持续集成。

此描述只陈述已实现的功能。没有真实用户量、增长率、模型准确率或性能提升证据，不应添加此类数字。

## 60 秒演示脚本

1. 展示默认两版提示词：A 是宽泛指令，B 要求 JSON 输出。
2. 展示共享测试用例，以及可配置的 JSON / 关键词检查。
3. 点击运行，说明当前是固定离线示例，不代表模型效果。
4. 查看矩阵，打开一个回答，展示检查详情与缺失 Token 的处理。
5. 导出报告，打开历史实验，说明结果为不可变快照。
6. 展示 .env.example 的字段名称，解释真实模型接入；不展示密钥。

## 传播建议

先展示“解决了什么具体问题”以及 30–60 秒操作录屏，再分享实现细节。向有提示词迭代需求的开发者征集具体用例，把反馈变成小版本。不要刷星、伪造用户反馈或声称离线示例证明提示词提升。

## 面试可解释点

- 为什么用同一批输入比较两版提示词，为什么一次演示不能证明统计优势。
- 为什么把规则检查和语义正确性区分开。
- 并发上限、超时、局部失败如何影响请求数、等待时间和费用。
- 为什么结果保存完整快照，编辑草稿不会改变历史记录。
- 为什么密钥留在服务端，个人本地部署与公共 SaaS 的边界在哪里。
